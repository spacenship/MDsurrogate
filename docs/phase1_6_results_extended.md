# Phase 1.6 extended metrics — Stage M, bounded seed 0

Generated by `scripts/analyze_phase1_6_extended.py` from records written by `scripts/evaluate_phase1_6_extended.py`.

**No model was trained for this report.** The seven Stage B checkpoints were reloaded, their sha256 verified unchanged before and after, and re-scored on the same validation manifest with a wider metric suite.

## 1. What this evaluation was for

Stage B separated the arms on two numbers: Cα RMSD and residue-frame rotation. `P1_pair_physics_frozen` improved rotation against `P0_pair_geometry_control` while being *worse* on Cα RMSD. Two numbers cannot say what that means, so this pass asks what kind of structure each arm is getting right:

* is the improvement in **internal** geometry (dRMSD by sequence separation) or only in placement?
* does any arm predict a contact **event** — a contact that forms or breaks between *t* and *t+lag* — rather than reproducing the contacts that never changed?
* does the reconstructed backbone stay physical?

It is a measurement pass. It does not decide Stage C, and one bounded seed cannot.

## 3. Metric definitions

| metric | definition | unit |
|---|---|---|
| `ca_rmsd` | RMS ‖pred Cα − target Cα‖ over valid residues, in the canonical frame (§4) | Å |
| `ca_rmsd_superposed` | as above after an **extra** per-sample Kabsch of the prediction onto the target | Å |
| `translation_rmse` | RMS ‖Δ̂_local − Δ_local‖. The residue origin **is** the Cα, so this is algebraically `ca_rmsd`; it is not an independent metric and is not read as one | Å |
| `rotation_geodesic_*_deg` | angle of `R̂ᵀR` per residue, via `atan2`, then mean / median over the sample | ° |
| `drmsd_*` | RMS of (‖x̂ᵢ−x̂ⱼ‖ − ‖xᵢ−xⱼ‖) over a pair subset. Alignment-free by construction | Å |
| `drmsd_local` / `medium` / `long_range` | `\|i−j\|` in 1–2 / 3–5 / ≥6, measured on source residue numbering within a chain | Å |
| `drmsd_current_spatial_edges` | the probe's own Cα-kNN edge set, built on the **current** frame only | Å |
| `contact_*` | Cα–Cα `d < 8.0 Å`, `\|i−j\| ≥ 6`, on the future structure | — |
| `formed_contact_*` | restricted to pairs **not** in contact at *t*; a true positive is a correctly predicted new contact | — |
| `broken_contact_*` | restricted to pairs **in** contact at *t* | — |
| `phi/psi/omega_mae_deg` | mean circular error `\|atan2(sin Δ, cos Δ)\|` on the reconstructed N/Cα/C backbone | ° |
| `bond_length_rmse` | C–N(next) peptide bond only — see §4 | Å |
| `bond_angle_mae_deg` | Cα–C–N(next) and C–N(next)–Cα(next) only | ° |
| `ca_neighbor_distance_mae` | `\| ‖x̂ᵢ₊₁−x̂ᵢ‖ − ‖xᵢ₊₁−xᵢ‖ \|` over bonded neighbours | Å |
| `clash_rate` | fraction of Cα pairs with `\|i−j\| ≥ 2` closer than 3.6 Å. **Cα-only**, not an all-atom clash rate | — |

### Metrics this reconstruction cannot support

Reported as `null` with the reason below, never as 0.

| metric | why not |
|---|---|
| `angle_n_ca_c_mae_deg` | intra-residue: N, CA and C of one residue are rigidly transported together, so this angle is identical in prediction and target by construction |
| `bond_angle_violation_rate` | no canonical bond-angle range is defined in this repository; same reason as bond_length_violation_rate |
| `bond_ca_c_rmse` | intra-residue: same construction as bond_n_ca_rmse |
| `bond_length_violation_rate` | no canonical bond-length range is defined in this repository (residue_constants.py has no bond table) and no chemistry library is installed in the `md` env; choosing a threshold now would be choosing it after seeing the results |
| `bond_n_ca_rmse` | intra-residue: reconstruct_backbone carries the residue's current local N onto both the predicted and the target frame, so this error is identically zero by construction and measures nothing |
| `chirality_violation_count` | the model predicts residue frames, not atoms: there is no Cbeta in the reconstruction. Carrying the current local Cbeta onto the predicted frame would make chirality invariant by construction, and a check that cannot fail is not a measurement |
| `dssp_class` | neither mdtraj nor Biopython is installed in the `md` env, and a re-evaluation of frozen checkpoints must not add a dependency |
| `heavy_atom_clash_rate` | no side-chain coordinates are predicted; the Cα-only clash metric is reported instead and is labelled as such in clash_definition |
| `rmsf_flexibility_class` | the manifest samples 4 frames per trajectory; an RMSF over 4 frames is not an RMSF, and no reference trajectory is loaded by this evaluation |

## 4. Alignment and masking

`build_transition_target` fits **one** proper rotation (`det = +1`, no reflection, SVD in float64) taking the future Cα onto the current Cα, weighted by the residues valid in both structures, and moves the whole future structure by it. The prediction is built from the current frames, so prediction and target already share that canonical frame and every metric here is invariant to a rigid motion of the whole pair — asserted by test, not assumed.

`ca_rmsd` and `rotation_geodesic_mean_deg` therefore do **no second superposition**, which is what makes them the Stage B definitions. The `*_superposed` variants do one, and apply the *same* rotation `Q` to the frames (`R̂ → QR̂`) as to the coordinates, so the two are a consistent pair — the existing `ca_rmsd_aligned` + `rotation_geodesic_deg` was not.

A residue is excluded wherever the current frame, the future frame or the batch mask excludes it; a torsion is excluded across a chain break or a residue-numbering gap; a pair is excluded if either endpoint is. Every record carries the counts it actually used (`n_valid_residues`, `n_valid_pairs`, `n_valid_torsions`, `n_current_spatial_edges`).

**The future is read only to score.** No function in the metric path takes a model, and no conditioner accepts a `TransitionTarget`.

## 14. Physical validity

Only the inter-residue quantities are measurements. `reconstruct_backbone` carries each residue's **current** internal geometry onto the predicted frame and does the same for the target, so N–Cα, Cα–C, the N–Cα–C angle and Cβ chirality are identical on both sides by construction. They are reported as `null` in §3, not as 0.

The best arm is worse than the identity baseline in **10 of 10** of these cells. The direction is not a surprise once stated: "nothing moves" returns a real mdCATH frame, whose peptide bonds, backbone angles and packing are a real protein's, so it can only be beaten on chain geometry by a model that predicts chain geometry. These arms predict a **rigid update per residue frame** and each frame moves independently, so the bonds *between* residues absorb the error. Whatever the arms buy in Cα placement and pair distances, they pay for here.

Three things this does **not** say. It is not a defect in the metric: the same reconstruction is applied to prediction and target, so both carry the same intra-residue approximation (§3). It is not a training failure: the loss these checkpoints minimised has `clash: 0.0` and no bond term, so chain geometry was never optimised and this is what that costs. And it is not a reason to prefer the identity baseline, which is worse on every endpoint and predicts no transition event at all.

## 16. What one bounded seed can and cannot support

* **One training seed.** Every interval here is a domain cluster bootstrap over the *evaluation* set. It quantifies how much the result depends on which 30 proteins were held out. It says nothing about how much it depends on the training seed, and no across-seed standard deviation is quoted because none exists.
* A separation at 95% here is **not** a reproducible superiority. Phase 1.5 measured arms that differed by ~0.2% and needed three seeds to say anything about them.
* The budget is Stage B's: 6,000 steps, three replicas, 120 train domains. These are screening numbers.
* dRMSD, contacts and torsions are **structural** measures of a single deterministic endpoint prediction. None of them is a thermodynamic or kinetic quantity, and none is evidence about ensemble fidelity.
* A change in residue-frame rotation error is a change in predicted frame orientation. It is not, on its own, an improvement in molecular dynamics.
* `P3`, `P4` and `P5` were not run. No number is estimated for them.

## 17. Decision matrix

Read mechanically off the paired tables. A cell is `better/worse at both lags` only when the 95% domain-cluster interval excludes zero at 1 ns **and** 4 ns in the same direction.

| comparison | Cα RMSD | long-range dRMSD | rotation | contact F1 | formed-contact F1 | torsion MAE | clash rate | peptide bond |
|---|---|---|---|---|---|---|---|---|
| **P0−S0** | better at both lags | not separated | better at both lags | not separated | worse at one lag only | better at both lags | worse at both lags | not separated |
| **P1−P0** | worse at both lags | better at one lag only | better at both lags | not separated | worse at both lags | worse at both lags | better at both lags | better at one lag only |
| **P2−P1** | better at one lag only | worse at one lag only | worse at both lags | worse at one lag only | better at one lag only | not separated | worse at both lags | worse at one lag only |
| **S2−S0** | worse at one lag only | worse at both lags | better at one lag only | worse at one lag only | not separated | better at both lags | better at one lag only | better at both lags |
| **O−S0** | worse at one lag only | worse at one lag only | better at one lag only | worse at one lag only | worse at one lag only | better at one lag only | better at one lag only | better at both lags |

### What the brief's rules say about these cells

* **P0 vs S0** — Cα RMSD *better at both lags*, long-range dRMSD *not separated*. The two co-primaries do not both reproduce, so the pair-geometry architecture is supported only as far as the cells above state.
* **P1 vs P0** — rotation *better at both lags*, Cα RMSD *worse at both lags*, long-range dRMSD *better at one lag only*, contact F1 *not separated*, formed-contact F1 *worse at both lags*, torsion *worse at both lags*.
  Pair physics degrades at least one co-primary. Under the brief's rule the case for keeping it as a 1–4 ns transition conditioner is weak, and a `P3`/`P4`/`P5` full run is **not** recommended on this evidence.
* **P2 vs P1** — Cα RMSD *better at one lag only*. The explicit (F, τ, S) moment branch is not shown to add anything and is de-prioritised; its extra complexity is not carried into Phase 2 automatically.
* **Oracle vs S0** — Cα RMSD *worse at one lag only*. A conditioner reading ground-truth instantaneous forces does not beat the structure-only baseline **within this force encoding and this probe** at 1–4 ns. That is a statement about this setup, not about forces in general, and it is not an information-theoretic claim.
